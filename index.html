Irodori Video Uploader

株式会社いろどりの社内の動画投稿ツール

Irodori Video Uploaderは、株式会社いろどり（以下「当社」）が、当社のYouTubeチャンネル「カエルの学校」に、制作した動画を上げるための社内のツールです。使うのは当社の担当者だけで、一般の方には提供していません。

できること

  • 動画のファイルを上げる
  • 題、説明、タグ、カテゴリを入れる
  • 子ども向けかどうかと、改変・合成したコンテンツかどうかを設定する
  • 公開の日時を予約する
  • 再生リストに入れる、サムネイルを設定する
  • 上げる先を確かめるため、許可を受けたチャンネルの名前とIDを読む

しくみ

YouTube API Services（YouTube Data API v3）を使い、担当者のパソコンから直接YouTubeに送ります。間に当社のサーバーはありません。上げる前に、上げる内容を画面に示し、担当者の同意を得てから送ります。

使う前に

使う前に、プライバシーポリシーと利用規約に同意してください。このツールを使うことで、YouTube利用規約に従うことにも同意したものとします。

Irodori Video Uploader

An internal video upload tool of Kabushiki Gaisha Irodori

Irodori Video Uploader is an internal tool that Kabushiki Gaisha Irodori ("we") uses to upload the videos we produce to our own YouTube channel, "カエルの学校" (Kaeru no Gakko). Only our staff use it. It is not offered to the public.

What it does

  • Uploads video files
  • Sets the title, description, tags and category
  • Sets the made-for-kids setting and the altered or synthetic content disclosure
  • Schedules the publish time
  • Adds the video to a playlist and sets the thumbnail
  • Reads the name and ID of the authorized channel, to confirm the upload destination

How it works

It uses YouTube API Services (YouTube Data API v3) and sends data directly from our staff member's computer to YouTube. No server of ours is involved. Before each upload, it shows what will be uploaded and sends nothing until the staff member agrees.
